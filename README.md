# md2conf

Publish Markdown files to a Confluence wiki.

**Status: pre-MVP.** The rewrite is in progress and is tracked on the project board.
The command line interface carries the flags and environment variables below;
conversion and publishing arrive with later issues, so `md2conf` currently parses
its arguments, reports the Confluence site it resolved and stops.

## Upstream

This is a rewrite of [hunyadi/md2conf](https://github.com/hunyadi/md2conf) (Python, MIT).
We port the behaviour, not the Python idioms. The upstream notice is in
[NOTICE.md](NOTICE.md); this repository keeps its own MIT [LICENSE](LICENSE).

## Requirements

Node.js 22.15 or later.

## Usage

```console
$ npx md2conf --version
0.0.0

$ npx md2conf --help
```

`md2conf` takes one or more Markdown files or directories to convert and publish.

### Command line

The flag names, defaults and help text are upstream's. A flag that is not listed here
does not exist yet: upstream's flags for features outside the MVP are left out rather
than accepted and ignored.

| Option                                                 | Description                                                                                                                      |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `<mdpath>...`                                          | Path to Markdown file or directory to convert and publish.                                                                       |
| `-d`, `--domain DOMAIN`                                | Confluence organization domain. (env: `CONFLUENCE_DOMAIN`)                                                                       |
| `-p`, `--path PATH`                                    | Base path for Confluence. (env: `CONFLUENCE_PATH`; default: `/wiki/`)                                                            |
| `--api-url API_URL`                                    | Confluence API URL. Required for scoped tokens. Refer to documentation how to obtain one. (env: `CONFLUENCE_API_URL`)            |
| `-u`, `--username USERNAME`                            | Confluence user name. (env: `CONFLUENCE_USER_NAME`)                                                                              |
| `-a`, `--api-key API_KEY`                              | Confluence API key. Refer to documentation how to obtain one. (env: `CONFLUENCE_API_KEY`)                                        |
| `-s`, `--space SPACE`                                  | Confluence space key for pages to be published. If omitted, will default to user space. (env: `CONFLUENCE_SPACE_KEY`)            |
| `-l`, `--loglevel {debug,info,warning,error,critical}` | Use this option to set the log verbosity.                                                                                        |
| `--root-page CONFLUENCE_PAGE_ID`                       | Confluence page to act as initial parent for creating new pages. Defaults to space home page. (env: `CONFLUENCE_PAGE_ID`)        |
| `--keep-hierarchy`                                     | Maintain source directory structure when exporting to Confluence.                                                                |
| `--skip-hierarchy`                                     | Flatten directories with no `index.md` or `README.md` when exporting to Confluence. (default)                                    |
| `--title-prefix STR`                                   | String to prepend to Confluence page title for each published page.                                                              |
| `--no-title-prefix`                                    | Use Markdown title to synchronize page. (default)                                                                                |
| `--generated-by MARKDOWN`                              | Add prompt to pages. (default: This page has been generated with a tool.)                                                        |
| `--no-generated-by`                                    | Do not add 'generated by a tool' prompt to pages.                                                                                |
| `--attachment-sync {full,upsert,create}`               | Synchronization mode for Confluence page attachments. (default: full)                                                            |
| `--skip-update`                                        | Skip saving Confluence page ID in Markdown files.                                                                                |
| `--keep-update`                                        | Inject published Confluence page ID in Markdown files. (default)                                                                 |
| `--heading-anchors`                                    | Place an anchor at each section heading with GitHub-style same-page identifiers.                                                 |
| `--no-heading-anchors`                                 | Omit the extra anchor from section headings. (May break manually placed same-page references.) (default)                         |
| `--force-valid-url`                                    | Raise an error when relative URLs point to an invalid location. (default)                                                        |
| `--no-force-valid-url`                                 | Emit a warning but otherwise ignore relative URLs that point to an invalid location.                                             |
| `--skip-title-heading`                                 | Remove the first heading from document body when it is used as the page title (does not apply if title comes from front-matter). |
| `--keep-title-heading`                                 | Keep the first heading in document body even when used as page title. (default)                                                  |
| `--prefer-raster`                                      | Prefer PNG over SVG when both exist. (default)                                                                                   |
| `--no-prefer-raster`                                   | Use SVG files directly instead of preferring PNG equivalents.                                                                    |
| `--render-mermaid`                                     | Render Mermaid diagrams as image files. (Installed utility required to convert.) (default)                                       |
| `--no-render-mermaid`                                  | Upload Mermaid diagram sources as Confluence page attachments. (Marketplace app required to display.)                            |
| `--diagram-output-format {png,svg}`                    | Format for rendering Mermaid and draw.io diagrams. (default: png)                                                                |
| `--task-lists`                                         | Transform GitHub/GitLab-style task lists into Confluence task list objects. (default)                                            |

| `--use-panel`                                          | Transform admonitions and alerts into a Confluence custom panel.                                                                 |
| `--no-use-panel`                                       | Use standard Confluence macro types for admonitions and alerts (info, tip, note and warning). (default)                          |
| `--force-valid-language`                               | Only allow supported languages in code blocks (unsupported languages are ignored) (default)                                      |
| `--no-force-valid-language`                            | Use unknown language names as-is (Confluence may still highlight code).                                                          |
| `--layout-image-alignment {center,left,right}`         | Alignment for block-level images and formulas.                                                                                   |

| `--layout-table-width INT`                             | Maximum table width in pixels.                                                                                                   |

### Environment variables

Confluence organization domain, base path, username, API token and space key can be
specified at runtime or set as Confluence environment variables (e.g. add to your
`~/.profile` on Linux, or `~/.bash_profile` or `~/.zshenv` on macOS):

```sh
export CONFLUENCE_DOMAIN='example.atlassian.net'
export CONFLUENCE_PATH='/wiki/'
export CONFLUENCE_USER_NAME='levente.hunyadi@instructure.com'
export CONFLUENCE_API_KEY='0123456789abcdef'
export CONFLUENCE_SPACE_KEY='SPACE'
```

If you use Atlassian scoped API tokens, you may want to set API URL directly,
substituting `CLOUD_ID` with your own Cloud ID:

```sh
export CONFLUENCE_API_URL='https://api.atlassian.com/ex/confluence/CLOUD_ID/'
```

This release also accepts `CONFLUENCE_PAGE_ID` as the fallback for `--root-page`, which
upstream does not read. A deployment can therefore set the parent page without editing
every command line:

```sh
export CONFLUENCE_PAGE_ID='19840101'
```

A command-line flag wins over the environment variable it corresponds to, and the
API key never appears in the log, not even at `--loglevel debug`.

## Document properties

_md2conf_ reads a page ID, a space key and a `generated-by` note from HTML comments, and the
rest of the page settings from YAML or JSON front-matter (the front-matter itself may also be
wrapped in an HTML comment). The comments are the same as upstream's:

```markdown
<!-- confluence-page-id: 19840101 -->
<!-- confluence-space-key: SPACE -->
<!-- generated-by: This page has been generated with md2conf. -->
```

The front-matter keys, with upstream's spelling:

```yaml
---
# page title; otherwise the first top-level heading is used
title: 'Example document'
# Confluence page ID, also accepted as confluence_page_id; needs no quotes
page_id: 19840101
# Confluence space key, also accepted as confluence_space_key
space_key: SPACE
# page labels
tags: ['markdown', 'md']
# false keeps the page content in Confluence only
synchronized: true
# page properties to apply
properties:
  content-appearance-published: full-width
# layout options for this page
layout:
  alignment: left
  image:
    alignment: left
    max_width: 640
  table:
    width: 640
    # or responsive (default)
    display_mode: fixed
---
```

A key the scanner does not know is ignored, and reported in the debug log. Keys that upstream
supports but this release does not yet, such as `folder_id` for Confluence folders, are ignored
the same way.
